# Архив источников

Локальные копии найденных источников. Хранятся, чтобы не искать их повторно и сохранить редакцию или версию на дату обращения.

Навигатор по источникам — [research/SOURCES.md](../research/SOURCES.md) (нормы, соглашения, литература) и [research/CASES.md](../research/CASES.md) (судебные акты). В карточке источника указывается путь к его папке здесь.

## Структура

```
sources/<ID>/
  <оригинал>.pdf | .html   — файл в том виде, в котором получен
  text.md                  — извлечённый текст (для поиска и цитирования)
```

ID совпадает с ID в реестре: `N-` — нормы, `C-` — судебные акты, `P-` — соглашения и правила платформ, `L-` — научная и аналитическая литература.

## Что попадает в публичный репозиторий

Только `N-*` (нормативные акты не охраняются авторским правом, п. 6 ст. 1259 ГК РФ) и этот файл. Остальные папки исключены в `.gitignore`:

- `L-*`, `P-*` — охраняются авторским правом;
- `C-*` — акты, полученные из КАД, могут содержать необезличенные персональные данные.

Эти папки есть только локально. Для передачи соавтору использовать канал вне публичного репозитория.
