# Архив источников

Локальные копии найденных источников. Хранятся, чтобы не искать их повторно и сохранить редакцию или версию на дату обращения.

Навигатор по источникам — [research/SOURCES.md](../research/SOURCES.md) (нормы, соглашения, литература) и [research/CASES.md](../research/CASES.md) (судебные акты). В карточке источника указывается путь к его папке здесь.

## Структура

```
sources/<ID>/
  meta.txt        — адрес, дата обращения, кто и как получил текст (обязателен)
  page.html       — страница, сохранённая tools/fetch_page.py или IA из браузера
  <оригинал>.pdf  — исходный файл, если документ получен в PDF
  text.md         — текст для поиска и цитирования (извлечён скриптом или передан IA)
  прочие файлы    — со смыслом в имени: guarantees.html (данные оператора),
                    cloudflare_403_S-50.html и .meta.txt (свидетельство блокировки, S-50)
```

Правила ID:
- префикс: `N-` нормы, `C-` судебные акты, `P-` соглашения и правила платформ и бирж, `L-` литература;
- языковая версия того же документа — суффикс `-ru` (P-01-ru, P-06-ru, P-07-ru); версии могут быть разными редакциями — дата в `meta.txt`;
- документ того же оператора на другом уровне — составной ID (P-03-L2: соглашение на игру Lineage 2 при сервисе P-03);
- в одном файле может быть несколько документов с совпадающей нумерацией пунктов (P-03-L2: соглашение и Правила игры) — в ссылке указывать документ;
- источник, полученный от IA, переносится из `temp/` без изменений; в `meta.txt` — «сохранено IA из браузера» / «скопировано IA вручную» / «сконвертировано IA».

## Что попадает в публичный репозиторий

Только `N-*` (нормативные акты не охраняются авторским правом, п. 6 ст. 1259 ГК РФ) и этот файл. Остальные папки исключены в `.gitignore`:

- `L-*`, `P-*` — охраняются авторским правом;
- `C-*` — акты, полученные из КАД, могут содержать необезличенные персональные данные.

Эти папки есть только локально. Для передачи соавтору использовать канал вне публичного репозитория.
