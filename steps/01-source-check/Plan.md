# Plan.md — шаг 1 «Проверка исходных источников» (micro)

## 0. Контекст
- Учебное исследование; micro-план шага 1 из `Plan_global.md`.
- Требования: `spec.md` §5.1 («проверен» = редакция с датой + соответствие тезису + точная цитата с пунктом), §5.3 (архив).

## 1. Статус
- Срок: фаза I, до 18.10.2026.
- Секреты не используются; полный текст Steam SSA — только локально (`sources/P-01/`, вне git).
- Источник контекста: `research/SOURCES.md`, раздел «Исходные источники».

### 1.1 Целевой сценарий
IA открывает карточку источника в `research/SOURCES.md` → видит редакцию, дату обращения, точную цитату с пунктом и вывод «подтверждает / не подтверждает тезис» → открывает `sources/<ID>/text.md` и находит ту же цитату → присваивает статус «проверен» или возвращает на доработку.

## 2. Требования к результату
- Результат: карточки N-01–N-04 и P-01 по шаблону «Карточка нового источника»; архив `sources/N-01…N-04/` и `sources/P-01/`; строки в `SEARCH_LOG.md`; инструмент загрузки страниц `tools/fetch_page.py`.
- Не делаем: N-05 (блок VP — пометка «проверку выполняет VP»); анализ действительности условий Steam по российскому праву (шаг 5); статус «проверен» (присваивает IA).
- Согласованные решения (12.10.2026):
  1. Текст для цитат получается `tools/fetch_page.py` (Playwright из `env/venv`, D-13): исходный HTML и извлечённый текст без пересказа; одна страница — одно обращение. Встроенная загрузка страниц Claude Code для цитат не используется (возвращает пересказ).
  2. Из `sources/N-*` в git — только `text.md`; HTML — локально (`sources/N-*/*.html` в `.gitignore`).
  3. N-04 (ст. 141.1 ГК) проверяется по открытой странице КонсультантПлюс; ссылка на Гарант сохраняется как вторая; сверка с Гарантом — запрос к IA (D-12).
- Файлы, разрешённые к изменению: `research/SOURCES.md` (раздел «Исходные источники» и карточки), `research/SEARCH_LOG.md`, `.gitignore` (решение 2), `Plan_global.md` (факт шага 1); новые — `tools/fetch_page.py`, `sources/N-01…N-04/`, `sources/P-01/`, этот файл.
